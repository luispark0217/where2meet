# 디자인팀 확인 요청 (은수)

퍼블리싱하면서 발견한, **피그마 시안 자체에 있는** 문제와 요청 사항이에요.
코드는 피그마 그대로 만들었고, 아래는 정해주면 반영할게요.

## 1. 숫자가 화면끼리 안 맞아요 (데이터 규칙 확인 필요)

| 화면 | 내용 | 충돌 |
|---|---|---|
| A·B·D vs G | 대학 동기 모임 왕 자리 **3곳** | G 랭킹에서는 **11곳** |
| A·B vs G | 필름 동아리 왕 자리 **5곳** | G 랭킹에서는 **14곳** |
| B vs F | 대학 동기 모임 약속 **24회** | F에서 동교동 와인바 한 곳만 방문 **29회** |
| A | 필름 동아리 "시간 정하는 중 · **4/6**" | 멤버는 8명 |
| G | "2위 · 1위까지 왕 자리 **3곳** 남았어요" | 11곳 vs 14곳이면 3곳 더 얻어도 **동점** (4곳이 맞음) |
| D | 하단 "마포 2 · 성동 1" | 지도 위 왕관 핀 위치(마포 1, 강남 1)와 다름 |

→ 목업 숫자라 괜찮지만, 발표·사용자 테스트 전에는 하나로 맞추는 게 좋아요.
→ **"왕 자리"와 "방문 횟수" 정의**를 한 줄로 정해주세요. 예: 왕 자리 = 우리 모임이 1위인 장소 수, 방문 = 사진 인증된 모임 수.

## 2. 사용자가 헷갈릴 수 있는 부분

- B의 탭: "진행 중"에 **완료된 약속**(스터디 뒤풀이)과 **확정된 미래 약속**(생일 파티)이 섞여 있고 "예정"은 비어 있어요. 탭 기준을 정해주세요.
- "③ 레이스", "1등 도윤"이 무슨 뜻인지 첫 사용자는 몰라요 → 짧은 설명이나 툴팁이 필요해요.
- C의 "장소 리스트 보기"가 어느 화면으로 가야 하는지 없어요 (지금은 E 확대 지도로 연결).
- E의 "≡" 버튼이 무엇을 보여주는지 없어요 (지금은 G 랭킹 리스트로 연결).
- A "4개가 기다려요": 필터를 걸었을 때, 약속이 없는 모임이 있을 때 문구를 정해주세요.

## 4. 퍼블리싱을 더 정확하게 하려면

- 색·글자 스타일을 피그마 **Variables / Styles**로 등록해주세요 (지금은 화면마다 직접 입력돼 있어요).
- 탭 아이콘(홈·알림·마이)과 ● 메뉴, ⋯ 버튼의 **실제 아이콘**을 SVG로 주세요. 지금은 네모·글자로 대신하고 있어요.
- 왕관은 피그마 벡터를 받을 수 없어서 비슷하게 다시 그렸어요. 원본 SVG를 주면 교체할게요.
- 사진·지도 자리의 실제 예시 이미지가 있으면 좋아요.

## 5. 아직 없는 화면

알림, 마이, + 새 약속 만들기, 사진 인증(모임 인정), 줄다리기 진행, 장소 리스트, 레이스, 초대받은 친구 화면,
그리고 로딩 중 · 빈 화면 · 오류 화면. 오면 바로 붙일게요 (지금은 "준비 중" 화면으로 연결돼 있어요).

## 7. 문구·동작

- **M 줄다리기 안내 "꾹 누르고 있으면 내 쪽으로 한 칸씩"**: 실제로는 **한 번 누를 때마다 한 칸**이고, 꾹 눌러도 한 칸만 가요.
  (가) 문구를 "누를 때마다 내 쪽으로 한 칸 (남은 n번)" 으로 바꾸거나, (나) 진짜 '꾹 눌러 확인'(진행 링)으로 바꾸기 중 골라주세요.
  지금은 화면 글자는 피그마 그대로, 화면 읽기 프로그램에는 실제 동작("누를 때마다 한 칸")을 읽어줘요.
- **K "새 약속 잡기" / "새 모임 만들기"**: 두 카드가 '둘 중 고르기'인지 '바로 실행'인지 정해주세요. 지금은 둘 다 바로 실행이에요.
- **H "약속 초대" 두 줄**: 피그마는 글자 단위로 끊겨 "요" 가 혼자 둘째 줄에 가요. 웹은 낱말 단위로 끊어요 (그대로 두는 걸 권해요).

## 8. 크기

- **아래 큰 버튼 높이가 화면마다 달라요**: P·Q·K 56px, L 54px (+ 왼쪽 버튼 120px). 글자도 15px(P·L) / 16px(K·Q). 하나로 정하면 맞출게요.
- **누르는 자리 40px 미만** (WCAG 최소 24px 는 통과, 우리 기준 40~44px 는 미달):
  O "보러가기" 68×30 · "투표하기" 68×28 · 빠른 답장 32px, I 칭호 칩 28~30px, K 모임 칩 30px, N·H·Q 필터 칩 32~36px.
  (Q 랭킹 참가 스위치는 카드 전체를 누르도록 바꿔서 72px 가 됐어요.)

## 9. 없는 상태 (피그마에 추가 요청)

- **작은 폰(SE, 높이 640px 이하)의 M·R**: 지금은 아래 판을 줄이고(당기기 72px, 안내 문구 숨김) 지도를 줄여 사람·중간 지점·말풍선이 다 보이게 했어요. 정식 시안이 있으면 맞출게요.
- **가로 화면**: M 줄다리기·O 채팅은 가로(높이 360px)에서 지도·메시지 자리가 거의 없어요. 모바일 전용이면 앱(PWA)으로 낼 때 세로 고정을 권해요.
- **O 채팅 키보드가 올라온 상태**: 지금은 화면이 낮아지면 빠른 답장 줄을 숨기고 마지막 메시지를 계속 보여줘요.
- **P 투표 카드 320px 폭**: 투표한 사람 아바타가 왕 알약과 겹쳐서, 좁은 폰에서만 아바타를 7px 내렸어요.
- **Q 모임 이름 비었을 때 오류**: 입력칸 빨간 테두리 + 아래 한 줄 "모임 이름을 적어주세요" 로 임시 처리했어요.
- **긴 이름**: 모임·약속 이름이 길면 N 머리 알약, P·N·O 의 "왕: …" 알약은 말줄임(…)으로 잘라요.
