# 디자인팀 확인 요청 (은수)

퍼블리싱하면서 발견한, **피그마 시안 자체에 있는** 문제와 요청 사항이에요.
코드는 피그마 그대로 만들었고, 아래는 정해주면 반영할게요.

## 1. 숫자가 화면끼리 안 맞아요 (데이터 규칙 확인 필요)

| 화면 | 내용 | 충돌 |
|---|---|---|
| A·B·D vs G | 대학 동기 모임 왕 자리 **3곳** | G 랭킹에서는 **11곳** |
| A·B vs G | 필름 동아리 왕 자리 **5곳** | G 랭킹에서는 **14곳** |
| B vs F | 대학 동기 모임 약속 **24회** | F에서 동교동 와인바 한 곳만 방문 **29회** |
| A | 필름 동아리 "시간 정하는 중 · **4/6**" | 멤버는 8명 |
| G | "2위 · 1위까지 왕 자리 **3곳** 남았어요" | 11곳 vs 14곳이면 3곳 더 얻어도 **동점** (4곳이 맞음) |
| D | 하단 "마포 2 · 성동 1" | 지도 위 왕관 핀 위치(마포 1, 강남 1)와 다름 |

→ 목업 숫자라 괜찮지만, 발표·사용자 테스트 전에는 하나로 맞추는 게 좋아요.
→ **"왕 자리"와 "방문 횟수" 정의**를 한 줄로 정해주세요. 예: 왕 자리 = 우리 모임이 1위인 장소 수, 방문 = 사진 인증된 모임 수.

## 2. 사용자가 헷갈릴 수 있는 부분

- B의 탭: "진행 중"에 **완료된 약속**(스터디 뒤풀이)과 **확정된 미래 약속**(생일 파티)이 섞여 있고 "예정"은 비어 있어요. 탭 기준을 정해주세요.
- "③ 레이스", "1등 도윤"이 무슨 뜻인지 첫 사용자는 몰라요 → 짧은 설명이나 툴팁이 필요해요.
- C의 "장소 리스트 보기"가 어느 화면으로 가야 하는지 없어요 (지금은 E 확대 지도로 연결).
- E의 "≡" 버튼이 무엇을 보여주는지 없어요 (지금은 G 랭킹 리스트로 연결).
- A "4개가 기다려요": 필터를 걸었을 때, 약속이 없는 모임이 있을 때 문구를 정해주세요.

## 3. 글자 대비 (잘 안 보일 수 있어요)

| 색 | 쓰는 곳 | 대비 | 기준 |
|---|---|---|---|
| `#9ba197` 회색 on 흰 바탕 | 지도 화면 보조 글자, 탭 꺼진 상태 | 약 2.5 : 1 | 4.5 : 1 이상 권장 |
| `#6b716c` on `#121513` | 어두운 탭바 꺼진 탭 | 3.7 : 1 | 4.5 : 1 |
| 카테고리 글자색 (카·식·술·영·만) on 흰색 | 지도 핀 | 2.1~3.3 : 1 | 3 : 1 (큰 글자) |
| 흰 글자 on `#2db400` | 홍대입구역 라벨 | 2.8 : 1 | 4.5 : 1 |

→ 조금 더 진한 색을 정해주면 `src/index.css`에서 한 번에 바꿀게요.

## 4. 퍼블리싱을 더 정확하게 하려면

- 색·글자 스타일을 피그마 **Variables / Styles**로 등록해주세요 (지금은 화면마다 직접 입력돼 있어요).
- 탭 아이콘(홈·알림·마이)과 ● 메뉴, ⋯ 버튼의 **실제 아이콘**을 SVG로 주세요. 지금은 네모·글자로 대신하고 있어요.
- 왕관은 피그마 벡터를 받을 수 없어서 비슷하게 다시 그렸어요. 원본 SVG를 주면 교체할게요.
- 사진·지도 자리의 실제 예시 이미지가 있으면 좋아요.

## 5. 아직 없는 화면

알림, 마이, + 새 약속 만들기, 사진 인증(모임 인정), 줄다리기 진행, 장소 리스트, 레이스, 초대받은 친구 화면,
그리고 로딩 중 · 빈 화면 · 오류 화면. 오면 바로 붙일게요 (지금은 "준비 중" 화면으로 연결돼 있어요).
